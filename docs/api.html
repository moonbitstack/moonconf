At

pub(all) struct At

Where in a document a value was written.

The offset is in UTF-16 code units from the start of the source, which is what a StringView indexes by. Line and column are one-based, because that is how an editor counts, and an error a reader cannot find in their file is half an error.

A source that does not report positions — the JSON, YAML and TOML readers this package borrows keep the tree but not the offsets — fills in { at: 0, line: 1, column: 1 }, and says so where it matters.

errors

Refused

pub(all) suberror Refused

Why a configuration was refused, and where.

One error type for the whole repository's root package: reading a borrowed format, merging layers, looking a path up, binding to a model. A caller catches one thing and reads one message. The message names the source and the position when the value came from text, and names the field path — db.pool.size — whenever the refusal is about a place in the tree, because a message that says "expected an integer" without saying where is a message that sends the reader looking through the whole file.

Variants
  • Type(want~ : String, got~ : String, path~ : String, source~ : String, at~ : At)

    A value has the wrong shape. path is empty when the refusal is about a value asked for on its own, with no place in the tree to name.

  • Missing(path~ : String, want~ : String)

    A field the model requires was nowhere in the sources.

  • Unknown(path~ : String, got~ : String)

    A member no field of the model describes, under a closed binding.

  • Clash(path~ : String, first~ : String, second~ : String)

    Two layers carried the same scalar and the clash policy refused both.

  • Path(got~ : String, at~ : Int32)

    A path that does not parse: an empty segment, a stray dot.

  • Format(why~ : String, at~ : At?)

    A borrowed reader refused the document, or a value it produced could not be carried into the tree. at is the position the reader reported, when it reported one.

  • TooDeep(at~ : At, limit~ : Int32)

    Nesting past the limit. A document of ten thousand opens must not take the stack down with it.

parse

pub fn parse(StringView, knobs? : Knobs) -> Doc raise Refused

Read an INI text.

Section headers stand at the start of a line; an option is a name, a delimiter, and a value; a line that starts with whitespace continues the value above it, joined with a newline, which is how a value spans lines in every file that has ever had a long one. A comment is a line of its own, starting with # or ;, and by default a # after a value is part of the value.

Options before the first header are refused rather than collected into a section nobody named: a file has a section, and a reader that invents one hides the missing line.

Knobs

The defaults are the ones a file in the wild is written for: = and : both separate, # and ; start a comment line, option names are folded to lower case, a repeated name is an error, and %(name)s is interpolated. parse

pub fn parse(StringView, source? : String) -> Doc raise Refused

Read a .env text into its assignments, in file order.

The grammar is the one .env files share in the wild:

  • KEY=VALUE, with an optional export in front and optional spaces around

the sign; KEY alone names a variable without giving it a value.

  • A key may be quoted, for a name with a space in it.
  • # at the start of a line, or after whitespace, starts a comment. A #

with a character before it is part of the value.

  • Single quotes take a value literally apart from \' and \\; double

quotes decode \n, \t, \r, \a, \b, \f, \v, \\, \' and \"; either may span lines.

  • A line that is none of those is kept in Doc::skipped, not made into an

error, so one stray line does not cost a deployment its configuration.

References are not resolved here: load does that, because a reference needs the entries above it.

The syntax is JSON's with the punctuation relaxed — no commas needed, no quotes around a word that has no punctuation in it, = or : before a value, # or // starting a comment — plus the three things that make it a configuration language rather than a data format:

this package reads a second file without doing any I/O itself.
