Four sources.
One reading.

INI, Java properties, .env, HOCON and HCL, read into a single tree. Layer it by tier, look a value up by path, bind the result to a model. Every value keeps the file and line it came from, so the answer to “where did this come from?” is in the answer itself.

Fig. 01 — the line

Read. Merge. Look up. Bind.

one pass
bytes → record

Each plate of settings turns into the same tree, the tree is merged once, and everything after that — a lookup, a check, a bound record — reads the merged result rather than the files.

01 — read

Read

A format package turns text into a tree and records where each value sits. No file is opened: the caller has the bytes already.

@ini.parse(text).tree(source="app.ini")

02 — merge

Merge

Tiers decide which of two values wins. Mappings merge member by member, so a file that sets one key keeps the rest.

@moonconf.merge(sources)

03 — look up

Look up

A dotted path walks the tree. Missing, mistyped and undescribed are three different refusals, not one null.

merged.need("db.port")

04 — bind

Bind

A model says what a valid section is. Binding fills the defaults, reads text as the type it spells, and names the field it refused.

@moonconf.bind(section, model)

01

Five readers

INI with its dialects, Java properties with its escapes, .env with its quotes, HOCON with its references, HCL with its expressions. JSON, YAML and TOML arrive through of_json, of_yaml and of_toml.

@ini · @props · @dotenv · @hocon · @hcl

02

Four tiers

Defaults, the file, the environment, an explicit override. The field wins orders them and can be reversed; the field clash says what a disagreement means.

Knobs { wins, clash }

03

Provenance

Each node carries the name of the source it was read from and the line it sat on. The bench on this page colours every value by the layer that won it.

node.source · node.at.line

04

Refusals, not nulls

Missing, Type, Unknown, Clash, Path, Format: each says the path it was about and where that path was written.

db.port (env@1:1): want integer, got text

05

Bound to a model

A Model from moonmodel describes the section: required fields, defaults, nesting. validate reports every problem; bind stops at the first.

bind(section, model) · validate(…)

06

Switches with names

Delimiters, comment marks, case folding, strictness, two interpolation modes, three policies for an unset variable, four expansion modes. Every switch is a named field or a preset.

@ini.Knobs · @expand.Unset

Fig. 03 — a whole run

One deployment, four sources, one record.

src/examples/tour
moon run
moonbitapp/main.mbt
// What the program carries.
let defaults = @moonconf.Node::map([
  ("db", @moonconf.Node::map([
    ("host", @moonconf.Node::str("localhost", "defaults")),
    ("port", @moonconf.Node::num(5432, "defaults")),
  ], "defaults")),
], "defaults")

// What the deployment shipped, and what the machine says.
let file = @ini.parse(
  "[db]\nhost = db.internal\npool = 8\n",
).tree(source="app.ini")

let env = @moonconf.Node::map([
  ("db", @moonconf.Node::map([
    ("port", @moonconf.Node::str("6432", "env")),
  ], "env")),
], "env")

let merged = @moonconf.merge([
  @moonconf.Source::new(@moonconf.Env, "env", env),
  @moonconf.Source::new(@moonconf.Default, "defaults", defaults),
  @moonconf.Source::new(@moonconf.File, "app.ini", file),
])

println(merged.need_text("db.host"))   // db.internal
println(merged.need_text("db.port"))   // 6432

// A model turns the section into a record, with types and defaults.
let db = @moonmodel.Model::new("Db", [
  @moonmodel.Field::new("host", @moonmodel.Type::Text, required=true),
  @moonmodel.Field::new("port", @moonmodel.Type::Int, required=true),
  @moonmodel.Field::new("pool", @moonmodel.Type::Int,
    default=Json::number(4.0)),
])
println(@moonconf.bind(merged.need("db"), db).stringify())

The verbs
CallAnswers
parseThe document as written: entries, sections, lines.
treeThe same document as the shared tree, with positions.
dumpsThe document back as text, in the file's own shape.
of_json · of_yaml · of_tomlA tree from a serialisation, for a caller that already has one.
mergeOne tree from a stack of sources, ordered by tier.
find · needA value at a dotted path, present or required.
bind · validateA record as the model describes it, or every reason it is not.

PolicyWhat happens
